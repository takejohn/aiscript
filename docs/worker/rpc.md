## Worker間通信の階層モデル
Worker間通信において，チャンネルメッセージングAPIが提供されている．
チャンネルメッセージングAPIは複製可能なオブジェクトを送信し，イベントとして受信する原始的なAPIである．
そのため，Worker間の通信を階層モデルにより抽象化する．

### 第4層: 参照オブジェクトの取り扱い
シリアライズ不可能なオブジェクトを参照として扱う．

### 第3層: シリアライズ可能オブジェクトの取り扱い
シリアライズ可能オブジェクトを受け取り，デシリアライズ可能オブジェクトを返す関数の遠隔呼び出しを実現する．
```typescript
interface Serializable<T extends Clonable = Clonable> {
	[serialize](): Clonable;
}

// Deserializable
// 複製可能オブジェクトにタグを付けて対応するDeserializerを呼び出し
```

### 第2層: RPC
リクエストとレスポンスの対応を把握する．
複製可能オブジェクトを受け取り，別の複製可能オブジェクトを返す関数の遠隔呼び出しを実現する．

### 第1層: チャンネルメッセージングAPI
MessagePortにより，複製可能オブジェクトの送受信を行う．
このAPIはWeb標準により提供される．
